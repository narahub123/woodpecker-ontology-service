# woodpecker-ontology-service

## 프로젝트 폐기

**이 프로젝트는 2026-09-27부로 폐기되었습니다.**

### 폐기 사유

AI를 이용한 구현 과정에서 작업 범위와 확정된 계약을 지속적으로 통제하지
못했고, 이미 `development`에 merge된 구현에서도 계약에 직접 고정되지 않은
physical design이 임의로 설계·확정된 사실이 확인되었습니다.

동일한 유형의 문제가 반복되었으며, 현재 방식으로 개발을 계속할 경우 추가적인
시간과 비용 손실 위험이 크다고 판단하여 프로젝트 전체를 폐기했습니다.

이 저장소의 기존 코드, 설계 및 구현 기록은 **후속 구현·재개·정본 기준으로
사용하지 않습니다.**
