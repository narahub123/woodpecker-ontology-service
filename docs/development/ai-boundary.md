# AI 경계 규칙

- 규칙과 알고리즘으로 결정할 수 있는 처리는 LLM에 위임하지 않습니다.
- 모든 AI 호출은 공통 `AiGateway`와 비용 정책 검사 및 사용량 기록을 통과해야 합니다.
- 분석 도메인과 API 계층에서 공급자 SDK를 직접 호출하지 않습니다.
- 모델 출력은 제안일 뿐이며 JSON Schema, 근거 참조, 유형, revision과 사용자 소유권을
  검증한 뒤 처리합니다.
- 모델이 `active`, `confirmed`, `merged` 상태를 직접 확정하게 하지 않습니다.
- 프롬프트와 로그에는 작업에 필요한 최소 데이터만 포함하고 비밀정보를 기록하지 않습니다.
- 테스트에서는 공급자 호출을 adapter 뒤로 격리하고 결정적인 fixture를 사용합니다.
