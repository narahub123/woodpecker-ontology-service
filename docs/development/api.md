# API 규칙

- 현재 MVP의 사용자 인터페이스는 OpenAPI와 JSON Schema 계약입니다.
- 경로, 쿼리, 헤더와 본문을 경계에서 검증하고 검증되지 않은 값을 도메인 계층에 넘기지
  않습니다.
- 사용자 경계는 검증된 JWT의 `sub`를 기준으로 강제합니다.
- 분석 작업은 동기 실행하지 않고 등록 후 `202 Accepted`로 응답합니다.
- 오류 응답은 공통 오류 형식을 사용하며 내부 구현이나 비밀정보를 노출하지 않습니다.
- 계약 변경에는 합성 요청·응답 예제와 계약 검증을 함께 갱신합니다.
- Woodpecker 또는 Supabase 데이터베이스를 직접 읽는 API를 만들지 않습니다.
