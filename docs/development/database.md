# 데이터베이스 규칙

- Ontology Service 데이터의 원본은 전용 Neon PostgreSQL입니다.
- Woodpecker 또는 Supabase 데이터베이스를 직접 조회하거나 수정하지 않습니다.
- 사용자 소유 데이터는 JWT `sub`에서 유도한 소유자 식별자로 격리합니다.
- 모든 스키마 변경은 순서가 있는 마이그레이션으로 작성하고 적용 및 롤백 위험을 기록합니다.
- 제약 조건과 인덱스는 애플리케이션 검증을 보완하며 사용자 경계를 데이터 계층에서도
  방어합니다.
- 노트 원문 전체를 저장하지 않고 계약에서 허용한 최소 근거와 파생 데이터만 보존합니다.
- 사용자 확정, 수정 또는 거부 결과를 자동 분석이 덮어쓰지 못하게 합니다.
