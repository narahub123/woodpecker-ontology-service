# 테스트 규칙

- 동작 변경에는 정상 경로와 실패 경로를 함께 검증하는 테스트를 추가합니다.
- 테스트는 실행 순서, 외부 네트워크, 실제 시각과 공유 상태에 의존하지 않게 작성합니다.
- 단위 테스트는 규칙과 상태 전이를, 계약 테스트는 공개 스키마와 예제의 일관성을 검증합니다.
- 사용자 경계가 있는 기능은 다른 `sub`의 데이터에 접근할 수 없는 사례를 포함합니다.
- AI 관련 테스트는 실제 공급자 호출 대신 결정적인 fixture와 adapter를 사용합니다.
- 테스트를 건너뛰거나 완화했다면 작업 기록에 이유와 남은 위험을 남깁니다.
- 기본 테스트 러너는 Vitest이며 `npm test`로 일회 실행합니다.
